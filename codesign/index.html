01The architecture

The same arrays.
A new connection.

A TPU-like chip combines large matrix arrays with a smaller vector path. The change is which data can reach those arrays.

Before / 1 of 3

Powerful arrays.
A limited entrance.

The four matrix arrays accept BF16 inputs. FP32 matrix operations take the 256-lane vector path instead.

The arrays already multiply and accumulate in FP32 internally. Their input route is the limitation.

The change / 2 of 3

Let full-precision
data through.

Add one ISA instruction. A new FP32 SRAM route and input selector let the existing arrays accept FP32 operands directly.

Scroll to watch the blue route appear. The original BF16 route stays in place.

The consequence / 3 of 3

More useful work.
The same four arrays.

ACT can now place this FP32 matrix work on any of the four arrays. The model's computation stays the same.

Added: routing, selection and instruction control. Array count, storage, assumed clock and bandwidth are fixed. Area and power have not been synthesized.

02The instruction set

A small addition.
A bigger vocabulary.

The ISA is the chip's vocabulary. TAIDL describes the new instruction's inputs, result and mathematical meaning.

Names below are simplified for explanation. The actual new opcode is gemm_f32_array_acc.

Before

  • LOAD / STOREMove data between HBM and SRAM.
  • GEMM_BF16BF16 matrix inputs → four arrays.
  • GEMM_FP32FP32 matrix inputs → vector unit.
  • ADD / NORM / SOFTMAX / …Vector arithmetic and normalization.

After

  • LOAD / STOREExisting instructions remain.
  • GEMM_BF16BF16 matrix inputs → four arrays.
  • GEMM_FP32The original vector path remains.
  • ADD / NORM / SOFTMAX / …The same vector operations.
  • + GEMM_FP32_ARRAYFP32 inputs → four existing arrays.
The meaning stays the same
C ← A × B + C

FP32 matrix inputs and accumulation. The new instruction exposes a different execution path for the same calculation.

Up to 128 rows × 256 contraction elements × 128 output columns per instruction.

The architecture recipe enables a supported instruction template. The Allo bridge provides its authored implementation and schedule.
